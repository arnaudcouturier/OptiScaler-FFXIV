# Settings reference

Generated by `tools/gen-settings.ps1` from `tools/settings-schema.json` checked against the C++ config (schema v1). Do not edit by hand: change the schema and re-run the generator.

Tagged keys: 180 across 14 sections.

How to read this: the keys go in the game folder's `OptiScaler.ini` under the `[Section]` heading; `auto` means "use the built-in default" (and for keys where `auto` is a real mode, the table says what it does); write a value to override.

Applies: live = the menu change applies at once; restart = needs a game restart; start = read once at start.
