# What works

What has been played in game and what has not, for every feature of this fork. The short version is in the [README](../.github/README.md); each feature, its origin and its settings are described in [FEATURES.md](FEATURES.md); installation is in [INSTALL.md](INSTALL.md).

## Release status

> **Status (October 2026): v0.4.0.** Tag `ffxiv-2026.10.30-d9b62110`, on OptiScaler nightly `d9b62110`. It was played in game on 2026-10-30 on one RTX 4090 in SDR (normal play with DLSS, DLSS-G and the HUD-less recomposition mode; not the whole play checklist). Before it: v0.3.0 (tag `ffxiv-2026.10.26-d9b62110`, played in game on 2026-10-26 on one RTX 4090 in SDR, adding the game build detection by pattern search and turning the upstream update check off). Before that: v0.2.0 (tag `ffxiv-2026.10.25-d9b62110`, played on 2026-10-25, adding the automatic ReShade scene depth) and v0.1.0 (tag `ffxiv-2026.10.23-d9b62110`, played on 2026-10-23). Download the zips from the Releases page. See the table below for what was played and what was not.
