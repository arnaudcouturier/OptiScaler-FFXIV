# Install guide

How to put OptiScaler-FFXIV into the game, what you have to bring yourself, how to turn features on and how to remove it again. The short version is in the [README](../.github/README.md); what was tested is in [STATUS.md](STATUS.md); every setting is in [FEATURES.md](FEATURES.md).

Download `OptiScaler-FFXIV-<version>.zip` from the [Releases](https://github.com/arnaudcouturier/OptiScaler-FFXIV/releases) page (releases are named by version, for example `v0.1.0`; tags and archive names use the date form `ffxiv-<yyyy.mm.dd>-<upstream sha8>[-rcN]`, see [RELEASE.md](RELEASE.md#release-numbering)), or build one yourself ([RELEASE.md](RELEASE.md)). The archive contains its own `INSTALL.txt` with the same steps.

1. **Back up first.** Close the game and the launcher. In the folder that contains `ffxiv_dx11.exe`, copy `winmm.dll`, `nvngx.dll_dlssnr.dll`, `OptiScaler.ini` and the `OptiScaler` folder to a new folder, for those that exist.
2. **Copy the files.** Extract the archive into that folder and overwrite. The archive holds `winmm.dll` (the fork's DLL, installed under the name the game loads), the NR forwarder `nvngx.dll_dlssnr.dll` (keep the exact name), `OptiScaler.ini`, the `OptiScaler` folder with third-party libraries, a `Licenses` folder, `NOTICE.txt` and `SHA256SUMS.txt`. Optional: compare hashes with `SHA256SUMS.txt`.
3. **Know the defaults.** Every value in the shipped `OptiScaler.ini` is `auto`, which means the built-in default: Neural Rendering, frame generation, HDR output, HUD-less, the DLSS-G unlock, window mode, the automatic multiplier, the automatic ReShade depth and the jitter correction and the source-level jitter fix are all off, and the game's own quality choice is left alone. Two behaviours are on by default in FFXIV: the automatic mipmap bias (`[Mipmap] MipmapBiasAuto`) and the quality change without the 500 ms pause (`[NgxRelease] SkipReleaseSleep`); set them to `false` to turn them off. The in-game menu opens with Insert; in FFXIV it has an FFXIV tab (window mode, HDR, game jitter, character preview, HUD-less, companion, advanced) that other games do not show. The menu keeps upstream's look unless you set `[Menu] Style=ember` (with your own `AccentColorR/G/B`). Set `[Log] LogToFile=true` to get `OptiScaler.log` for bug reports.
4. **Bring your own NVIDIA files.** They are not redistributable from this repository and are not in the archive: `nvngx_dlss.dll` (the game normally has one), `nvngx_dlssnr.dll` for Neural Rendering (beside OptiScaler as before, or one folder per version, `OptiScaler\NR.<version>\nvngx_dlssnr.dll`, to switch between versions in the menu), `nvngx_dlssg.dll` plus the Streamline plugins in `OptiScaler\streamline\` for DLSS-G frame generation, and for the experimental RTX 30 path a community companion runtime in `OptiScaler\dlssg_sm86\`. Get them from NVIDIA's DLSS and Streamline distributions; `INSTALL.txt` lists the exact names. HUD-less with ReShade presets and the automatic ReShade depth need your own ReShade 6.8.0.
5. **Turn features on** in the menu or in `OptiScaler.ini` (see [FEATURES.md](FEATURES.md) for every key). The set used in the author's tested setup, for DLSS on this DirectX 11 game: `[Upscalers] Dx11Upscaler=dlss_12`; Neural Rendering `[DlssNr] Enabled=true`; frame generation `[FrameGen] Enabled=true`, `FGInput=upscaler`, `FGOutput=dlssg`; HDR10 output `[HDR] FfxivHDR=true` with Windows HDR on (restart; `[HDR] Mode=1` adds RenoDX scene HDR); HUD-less `[HudLess] Mode=ui_free` (opt-in, needs DLSS-G output).
6. **Known limits.** Only the features marked tested in [STATUS.md](STATUS.md) were played, on one RTX 4090; everything else is untested. Window mode needs `[XeFG] ForceBorderless=true` (the borderless "fullscreen" of FFXIV with DLSS-G) and ReShade. HUD-less is opt-in and untested in HDR. The game jitter correction ran in game and scaled the told jitter (2026-10-20 and 2026-10-23); its earlier version showed no visible gain at the Quality mode (2026-10-19) in the author's test, the look of the current version is not recorded, and it stays experimental. Do not combine `[HudLess] Mode=recomposition` with DLSS-G Preset A or C: NVIDIA turns its UI recomposition off with them, so the fork does not request it (use Auto or B with `recomposition`, or `ui_free`, which is experimental). DLSS presets L and M cost more fps than K (they are heavier models); K stays the default. 5x and 6x multi frame generation on RTX 40 are experimental and one GPU hang happened at 6x: stay at 4x or lower. FFXIV-specific features follow one game build; after a game patch they switch themselves off until the fork is updated ([FFXIV-PATCH-RUNBOOK.md](FFXIV-PATCH-RUNBOOK.md)).
7. **Uninstall.** Close the game, delete the files and folders listed in step 2 (and `Licenses`, `NOTICE.txt`, `SHA256SUMS.txt`, `INSTALL.txt`), and copy your backup back.
