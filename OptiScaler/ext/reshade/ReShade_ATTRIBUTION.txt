ReShade add-on API headers
==========================

Project:  ReShade by crosire (Patrick Mours)
Source:   https://github.com/crosire/reshade , tag v6.8.0 , directory include/
Where:    OptiScaler/ext/reshade/third_party/reshade/  (8 files, vendored unmodified; see the README.md there for sizes and SHA-256)

What is used
------------

OptiScaler-FFXIV registers itself with the user's ReShade as a built-in add-on and talks to ReShade's effect runtime
through ReShade's public add-on API (reshade.hpp, reshade_api*.hpp, reshade_events.hpp, reshade_overlay.hpp). The
headers are compiled into OptiScaler; no ReShade binary or source code is shipped.
